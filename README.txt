AURA Metabolic — готовый HTML-сайт, ноябрь 2026

Установка на GitHub Pages:
1. Распакуйте архив.
2. Загрузите всё содержимое (index.html, aura.js, aura.css, store-links.js,
   favicon.png, папку assets и .nojekyll) в корень вашего репозитория.
   Не загружайте ZIP вместо его содержимого. Замените старые файлы сайта.
3. GitHub → Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Откройте адрес, который покажет GitHub Pages.

Обычный хостинг: загрузите содержимое в public_html.
Установка Node.js, Bun и сборка не нужны. Все фото входят в архив;
Google Fonts загружаются онлайн, без интернета используются системные шрифты.

Ссылки магазинов:
Откройте store-links.js любым текстовым редактором.
Поле googlePlay уже содержит предоставленную ссылку.
В appStore вставьте настоящий URL страницы приложения между кавычками.
Пока поле пустое, кнопка App Store недоступна. После добавления URL
она станет активной во всех местах сайта. Пересборка не нужна.

8 языков: English, Українська, Deutsch, Italiano, Español, Português,
Polski, Türkçe. Все 9 новых скриншотов в исходном качестве.
