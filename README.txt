AURA Metabolic — статический сайт
=================================

КАК ОПУБЛИКОВАТЬ НА GITHUB PAGES
1. Создайте репозиторий на GitHub (например, aura-site).
2. Загрузите в него ВСЁ содержимое этой папки (index.html должен быть в корне).
3. В репозитории: Settings → Pages → Source: "Deploy from a branch",
   ветка main, папка / (root) → Save.
4. Через 1–2 минуты сайт будет доступен по адресу
   https://<ваш-логин>.github.io/<имя-репозитория>/

КАК ДОБАВИТЬ ССЫЛКИ НА МАГАЗИНЫ
Откройте файл store-links.js в любом текстовом редакторе и вставьте
адрес приложения в кавычки напротив нужного магазина:
  googlePlay: 'https://play.google.com/store/apps/details?id=...'
  appStore:   'https://apps.apple.com/app/...'
Пока ссылка пустая (''), кнопка этого магазина на сайте скрыта.
Сохраните файл и обновите страницу — кнопка появится.
Пересборка сайта НЕ нужна.

ОБЫЧНЫЙ ХОСТИНГ
Загрузите содержимое папки в public_html (или корень сайта) по FTP.
